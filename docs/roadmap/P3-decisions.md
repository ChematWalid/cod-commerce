| D3125 | **Layered pricing** (user decision 2026-11-22). An optional sparse commune layer `delivery_fee_commune_rate` (fee group × ONS code) has nullable `base*`/`override*` prices and nullable delivery/desk switches. It has no database FK to `geo_town`; it is validated through geo's `TownDirectory` port. **Truth table** (the only statement of it). *Price* of a method = commune `override ?? base` (`source: 'commune'`), else wilaya `override ?? base` (`source: 'wilaya'`). *Delivery* = commune `deliveryEnabled ?? wilaya deliveryEnabled`, so an explicit commune `true` delivers even when the wilaya is off, and an explicit `false` blocks it. *Desk* = delivery && (commune `deskEnabled ?? wilaya deskEnabled`) && (no `townOns` or the town's reference `isStopdesk`). *Home* = delivery. Not offered gives `resolved:false`, fees 0, `source: null`. Without `townOns` the wilaya level alone applies. A `townOns` that is unknown, of another wilaya or malformed gives `resolved:false`. Overweight always comes from the group. Writes: merchant edits write `override*` (commune level compared with the commune base; a null base means any value is an override), `setDeliveryFeeCommuneRates` merges per row and never writes `base*`, and sync writes only `base*`. `overridden` = `override* IS NOT NULL`. | Yalidine bills per commune with several tiers inside one wilaya; checkout and support must explain a price. | A third layer (zones) would be another table. |
