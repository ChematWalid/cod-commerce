## Part deltas (new machine, 2026-11-07)
The P0.S2a-1 machine was Windows 11 with Docker Desktop disabled. This part runs on **Arch Linux, native Docker Engine 29.x** (no WSL2 VM), so:
- **User decision 3 (`.wslconfig`) does not apply.** Host RAM is 11.6 GB, shared with other running containers (≈ 4 GB free at start). Postgres keeps `shared_buffers=1GB`; record free memory next to every measurement.
- **Scratch:** `SCRATCH=$HOME/scratch/p0s2a2` (outside the repo), compose project `p0s2a2`.
- **Host ports** (3000, 6379 and 8080 are taken by unrelated local containers; P0.S2a-3 uses its own): Postgres `5433`, PgBouncer `6432`, Valkey `6380`, Vendure API `3100`, dashboard `5174`, worker health `3120+`. Meilisearch is not part of this stack (spike E belongs to P0.S2a-3).
- **Node:** host Node is 26; spikes run on **Node 24.22.1** through `mise exec node@24.22.1 --` to match ADR 0001.
- **Cold protocol:** `docker run --rm --privileged alpine sh -c 'sync; echo 3 > /proc/sys/vm/drop_caches'` drops the **host** page cache directly (no VM layer), which is closer to production than the WSL2 variant.
- No `MSYS_NO_PATHCONV`/`cygpath`; plain bash paths.
- `psql` runs inside the postgres container (`PSQL="docker compose -p p0s2a2 exec -T postgres psql -U postgres"`).
- Spike B code was not committed by P0.S2a-1 (project rule); it is rebuilt here from the ADR 0004/0009 excerpts, and the 9 100 DZD total is re-asserted on Postgres as a side effect.
