Kamal 2 deploys app roles; the data tier (Postgres 17 + PgBouncer + Valkey + Garage) stays on compose on the same host. OpenTofu manages only Cloudflare/DNS/R2 (ADR 0011). ## Global Constraints
- CLAUDE.md rules apply (layout, sizes, no `any`, no silent catch, typed fail-fast config, tests by behaviour).
- **No AI attribution** in commits/PRs; no `--no-verify`; never force-push.
- **Never mint or commit a secret**, not even a throwaway (memory rule). Secrets are referenced by name (`KAMAL_REGISTRY_PASSWORD`, `CLOUDFLARE_API_TOKEN`, …) with `.env.example` placeholders and a fail-fast check; local runs use the existing synthetic `${VAR:-…}` pattern of the evidence scripts.
- No account creation, no `tofu apply`, no `kamal setup` against a real host, no push to a registry from a laptop. Workflows that need secrets are gated: they skip with a clear notice when the `staging` environment/secret is absent.
- Source edits only under D3501 paths. Workflows: new files only (`ci.yml` job list and its no-secrets rule are pinned by `packages/config/tests/ci-workflow.test.ts`); every action SHA-pinned, every job `timeout-minutes` (`workflow-hygiene.test.ts`). Compose: no bind mounts, configs inline via `configs.content` (`scripts/check-compose-portability.mjs`); every new compose variable in root `.env.example` (`env-example.test.ts`).
- Object storage is **Garage** (repo state), not MinIO (brief drift, D3502).
- Docker images pinned by version (and digest where the tool supports it); pulling official images for local verification is allowed (D3503).
- Local checks only: lint/typecheck/unit of touched packages + `pnpm test:arch`; heavy runs one at a time under `flock -w 3600 /tmp/cod-heavy-jobs.lock timeout 2400`.

## Review Focus
1. A secret ending up in the repo, an image layer, build args, logs or workflow output (`docker history`, Trivy secret scan, `set -x` in scripts, echoing env).
2. A deploy that starts api/worker before `migrate` succeeded, or serves 5xx during rollout (drain: `/readyz` 503 at once on SIGTERM, 25 s request drain, 60 s job drain, ADR 0013).
3. Edge rules that leave `/store/*`, `/shop-api*`, `/_internal/*`, `/_t/*`, `/api/internal/*` reachable on any host, or a cache rule that stores 5xx/429 or per-buyer responses (D3226 f).
4. Backups or private objects written to R2 (ADR 0012: R2 = public assets only), or a restore test that passes without actually restoring.
5. Server hardening that locks out the operator (ufw before SSH allow, sshd config without a test) or opens 80/443 to the world instead of Cloudflare ranges.
