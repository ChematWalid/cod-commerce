> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (user's choice: "use agents") or superpowers:executing-plans to implement this plan task-by-task. Tasks run **sequentially** (one scratch app, one Docker stack); a fresh subagent per task is fine, a parallel fan-out is not.

**Goal:** Sixteen ADRs (`docs/adr/0001…0016-*.md` + index) that settle the base decisions, each risky one backed by a throw-away spike whose versions, commands and numbers are recorded in the ADR — one PR from `docs/p0-s2a-adrs`, not merged.

**Architecture:** Spikes run in a scratch folder **outside the repo** against a Docker Compose stack (Postgres 17, Valkey 8.1, PgBouncer, Meilisearch). A Vendure 3.8.1 scratch app (`@vendure/create`) hosts spikes A–D; a small Next 16 app hosts spike F; spike E is a script against three search backends. Results go into the ADR drafts, which move from `docs/adr/drafts/` to `docs/adr/NNNN-*.md`. Nothing but `docs/` is committed.

**Tech Stack:** Vendure 3.8.1 (`@vendure/core`, `@vendure/dashboard`, `@vendure/job-queue-plugin`, `@vendure/harden-plugin`, `@vendure/testing`), Node 24.22.1, npm 11.14.1 (pnpm not installed; one pnpm smoke in Task 3), Docker Desktop (WSL2 backend), `postgres:17`, `valkey/valkey:8.1.11`, `edoburu/pgbouncer` (tag pinned in Task 0, PgBouncer ≥ 1.21), `getmeili/meilisearch:v1.56.1`, Next.js 16.4.x, `http-proxy` (spike F round-robin, runs on the host), `pgbench` (inside the postgres container).

**Spec:** `docs/roadmap/P0-setup.md` → section "P0.S2a — Architecture ADRs & spikes" (high-level plan steps 1–5, deliverables, 7 acceptance criteria, verification). Inputs: `docs/adr/drafts/*` (start from them), `docs/architecture/roadmap-impact.md`, `docs/roadmap/handoff/P0.S1.md`, `docs/research/data-model.md` ("Storefront ordering protocol", "Product", "Order (dashboard)", "Billing"), `docs/research/api-surface.md`, `docs/repo-evaluation.md`.

A wrong tenancy or order-totals decision found in P3 costs several sessions; the spikes make the risky assumptions (channels at scale, PgBouncer transaction mode, Arabic search, shared Next cache, dashboard extensibility, COD totals) measurable before code lands.
