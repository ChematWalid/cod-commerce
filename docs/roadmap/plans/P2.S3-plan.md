**Goal:** Merchants build store collections in the dashboard (Products → Collections): image, title, description, slug, visibility and position, with either a hand-ordered list of products or automatic All/Any conditions on tag, brand, price, on sale, title and every option name of the store, a live debounced match preview, membership recomputed when a product changes, a public read for the storefront and a membership service for the offer sessions.

**Architecture:** New feature plugin `plugins/collections-rules` (layout of `plugins/_template`, patterns of `plugins/catalog`). Vendure `Collection` stays the identity and metadata row (translations, per-channel slug, featured image, store channel only — removed from the default channel like P2.S1's products, D2333), so catalog's D2134 id check and D2157 media-in-use keep working; rules, mode, visibility, position and ordered membership live in our own tenant tables, evaluated by pure domain code. **No `CollectionFilter`** and the stock all-collections recompute is switched off. Product facts come from a new batched, keyset-paged catalog extension point `CatalogProductFactsReader`; the catalog's product-collection links move behind a registrar `COLLECTION_MEMBERSHIP_SOURCE_REGISTRAR` (pattern of `SOLD_OUT_SOURCE_REGISTRAR`, D2163) that collections-rules fills. Every membership writer holds one per-store advisory lock (D2334). Membership is recomputed synchronously on rule save, asynchronously by an outbox consumer of `product.changed`, and by a store reconcile job (D2336). Public reads reuse `CatalogReadService` visibility (ADR 0017, D2109). The product-side picker is a collections-rules `pageBlock` on the catalog editor (D2105, D2324).

**Tech Stack:** Vendure 3.8.1, NestJS 12, TypeORM 0.3.31 (Postgres 17, Valkey 8), zod 4.6.7 in `@cod/shared`, React 19 + `@vendure/dashboard` 3.8.1 + Lingui `.po`, Tailwind 4.3.5, Vitest 5.1.0, `playwright-core` 1.65.0.

## Review Focus

1. **Tag deleted while a rule names it** (Task 4b, Task 8): deleting tag `promo` must drop its products from "Tag is any of [promo]" and add them to "Tag is not [promo]". Test: `collections-recompute.int.test.ts` "a tag delete recomputes the collections that name it"; catalog unit `tag.service.test.ts` "publishes product.changed for each product a tag delete unlinks".
2. **Arabic title text in another written form** (Task 2): rule "Title contains `حذاء`" matches `حِذاءٌ رياضي` (harakat), `حـــذاء` (tatweel), an NFD-stored title and the alef/ta marbuta/ya variants of D2305; "contains `SHOE`" matches `Running shoe`. Test: `packages/shared/tests/collections/text-normal.test.ts` "matches Arabic titles whatever their harakat, tatweel, letter variant or normal form".
3. **Option value carried only by a hidden variant** (Task 3, Task 4a): `Color is any of [Red]` does not match a product whose only Red variant is hidden; `Color is not [Red]` matches it; a product without a Color option matches `is not`. Test: `evaluate-rule.test.ts` "ignores hidden variants for option, price and on-sale conditions".
4. **Concurrent, duplicate or late delivery of `product.changed`** (Task 5, Task 8): the consumer takes the store lock (D2334) and only then reads rules and facts, so two deliveries of one product, a rule save racing a product edit, a redelivery, or an old `updated` after `deleted` all end with membership built from the latest committed facts and rules. Tests: `collections-recompute.int.test.ts` "a redelivered or stale event leaves membership unchanged", "concurrent deliveries of one product converge to its latest facts", "a product edit during a rule save ends with the correct membership".
5. **Store switch during a pending preview** (Task 12): a preview answer of store 1 arriving after the switch to store 2 is never shown (fetch refuses on a changed channel token, D2160). Test: `preview-request.test.ts` "drops a preview answer whose store is no longer active".
6. **Default-channel leak** (Task 6a): a created collection is in the store channel only. Test: `collections-crud.int.test.ts` "a created collection is not in the default channel"; e2e census cell.
