## Ordering traps (read before starting)

1. `main` must exist before anything else: `gh repo create --add-readme` seeds it with one commit (authored by the user). Protection is applied **after** the branch is pushed and CI has run, never before the PR exists.
2. A required check that never reports blocks every PR ("Waiting for status to be reported"); GitHub's UI only offers checks that ran in the last 7 days (https://docs.github.com/en/pull-requests/how-tos/merge-and-close-pull-requests/troubleshooting-required-status-checks). So: open PR → wait for the first run → set required contexts to the **exact job names** seen in `gh pr checks`.
3. The session's own PR must pass `attribution-check` → never write the literal trailer/footer strings in commits, PR title or body.
4. Admins bypass protection by default → set `enforce_admins: true` and `required_approving_review_count: 0` (solo owner can still merge after checks pass) (https://docs.github.com/en/rest/branches/branch-protection).
5. CI jobs must succeed with no `package.json` yet (P0.S2b adds it) → Node steps are guarded with `if: hashFiles('package.json') != ''`.

## Windows pitfalls

- **CRLF in hooks/scripts** makes bash fail with `\r: command not found` (hooks silently don't block). Fix: `.gitattributes` forces LF; create files with LF; verify with `git ls-files --eol .githooks scripts`.
- **Exec bit** doesn't exist on NTFS: run `git update-index --chmod=+x <file>` before committing; verify `git ls-files -s .githooks` shows mode `100755`.
- **winget PATH:** after `winget install --id GitHub.cli -e`, open a **new** terminal (or `refreshenv`) before `gh` is found.
- **Paths:** Git Bash uses `/c/Users/ASUS/...`; PowerShell uses `C:\Users\ASUS\...`. `robocopy` exit code `1` means success (copied files), `≥8` is failure.
- **gh in Git Bash:** prefer `gh ... --jq` over external `jq` (not installed).

## Review Focus (most likely to bite; each has a test in its task)

1. Hook stored with CRLF or without exec bit → never blocks commits. **Test:** Task 5 step "hook rejects a trailer message".
2. Required-check context typo (e.g. `CI / build-test`) → every future PR blocked forever. **Test:** Task 8 compares `gh pr checks` names to the protection JSON before applying.
3. Bootstrap re-run creates duplicate issues/milestones or drifts titles. **Test:** Task 6 runs twice; counts identical.
4. Secondary rate limit mid-run (80 content requests/min, 500/hour — https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) leaves a partial state. **Test:** Task 6 throttles (≤30/min) and is resumable (skip existing by exact title).
5. Admin bypass leaves `main` effectively unprotected. **Test:** Task 9 direct-push attempt is rejected while authenticated as the owner.

```yaml
name: CI
on:
  pull_request:
  push:
    branches: [main]
permissions:
  contents: read
concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true
jobs:
  build-test:
    name: build-test
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:17
        env:
          POSTGRES_USER: postgres
          POSTGRES_PASSWORD: postgres
          POSTGRES_DB: app_test
        ports: ["5432:5432"]
        options: >-
          --health-cmd "pg_isready -U postgres" --health-interval 5s
          --health-timeout 5s --health-retries 10
    env:
      DATABASE_URL: postgres://postgres:postgres@localhost:5432/app_test
    steps:
      - uses: actions/checkout@v4
      - name: No package.json yet (P0.S2b adds it)
        if: hashFiles('package.json') == ''
        run: echo "Skipping Node steps until P0.S2b"
      - uses: actions/setup-node@v4
        if: hashFiles('package.json') != ''
        with: { node-version: 24 }
      - name: Enable corepack
        if: hashFiles('package.json') != ''
        run: corepack enable
      - name: Install
        if: hashFiles('package.json') != ''
        run: pnpm install --frozen-lockfile
      - name: Lint
        if: hashFiles('package.json') != ''
        run: pnpm run --if-present lint
      - name: Typecheck
        if: hashFiles('package.json') != ''
        run: pnpm run --if-present typecheck
      - name: Test
        if: hashFiles('package.json') != ''
        run: pnpm run --if-present test
      - name: Build
        if: hashFiles('package.json') != ''
        run: pnpm run --if-present build
  attribution-check:
    name: attribution-check
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - name: Reject AI attribution in commits, PR title and body
        env:
          PR_TITLE: ${{ github.event.pull_request.title }}
          PR_BODY: ${{ github.event.pull_request.body }}
          BASE_SHA: ${{ github.event.pull_request.base.sha }}
          HEAD_SHA: ${{ github.event.pull_request.head.sha }}
        run: |
          pattern='co-authored-by:.*(claude|anthropic)|generated with .*claude'
          found=0
          if git log --format=%B "$BASE_SHA..$HEAD_SHA" | grep -iE "$pattern"; then echo "::error::AI attribution in commit messages"; found=1; fi
          if printf '%s\n%s\n' "$PR_TITLE" "$PR_BODY" | grep -iE "$pattern"; then echo "::error::AI attribution in PR title/body"; found=1; fi

```
