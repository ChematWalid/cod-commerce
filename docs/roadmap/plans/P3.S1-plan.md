> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkboxes (`- [ ]`). The P3 child rules (`~/.config/cod-autopilot/p3-child-rules.md`, **LIGHTER WORKFLOWS**) apply. Each task runs as one implementer agent (tests first, `tdd-workflow`), then one combined reviewer/verifier agent that checks correctness and re-runs the commands. There is at most one fix round, and leftover minors go to one follow-up issue. Tasks marked **RISKY** get the full adversarial review instead: tenant isolation, permissions, public endpoints, money totals and migrations. That means 2–3 verifier lenses (correctness; tenant isolation and security; does-it-reproduce) and fix rounds until clean. A null, missing or errored agent result counts as **not verified** and is re-run. Skills: `tdd-workflow` (every task), `database-migrations` (Tasks 3, 5), `security-review` (Task 13), `verification-loop` and `superpowers:verification-before-completion` (before every PASS).

**Goal:** Deliver the 69 wilayas (law 26-06 of 4 April 2026, D3123) with all 1,541 communes (ONS codes) and the public `/provinces` endpoints. Add per-store delivery-fee groups ("pricing options") with the seeded "Platform default prices" table, a shipping-quote service registered on the offer engine, and the Delivery → Delivery Pricing dashboard tab. Fix the cross-business reference holes in `updateStore` (#230, #153) and add the Default delivery fee group field to store settings (#207).

**Architecture:** There are two new plugins with the `_template` layout. `plugins/geo` holds global reference data: `geo_province` and `geo_town` are not tenant tables, are seeded idempotently from `infrastructure/seed/geo-seed.json`, and are read by a public cached REST controller. `plugins/delivery-pricing` holds the store-scoped `TenantEntity` tables `delivery_fee_group` and `delivery_fee_rate`, served through Admin GraphQL plus a REST mirror. It provides a pure domain quote function, a `ShippingQuoteService`, and an adapter registered on the offers `SHIPPING_QUOTE_REGISTRAR`. A tenancy lifecycle hook seeds a new store's default table. Tenancy gains a reference-check registrar that delivery-pricing fills, the same seam pattern as `TENANT_LIFECYCLE_REGISTRAR` and `ORDER_MANAGER_CHECK_REGISTRAR`.

**Tech stack:** Vendure 3.8.1 plugins (NestJS, TypeORM 0.3.31, Postgres), zod 4 contracts in `@cod/shared`, Vitest 5, the Vendure dashboard (React 19, Lingui) for the tab, and Playwright for the evidence.
