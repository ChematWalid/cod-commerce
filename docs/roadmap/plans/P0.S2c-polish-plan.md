## Findings that shape the plan

- `@vendure/dashboard` 3.8.1 has a supported login extension (`login.logo`, `login.beforeForm`), which replaces the logo and the welcome block.
- The footer (`LoginBranding`, `MenuBranding`, `[data-vendure-branding]`) has no supported override. The source forces it visible with `!important` and calls it "a licensing requirement". **It is not hidden or removed by this session unless the user decides so** (question sent to the coordinator; default is to keep it). CSS hiding is excluded in every case.
- Plugin `.po` files under a plugin's dashboard folder are merged into the catalogues at build (`vite-plugin-translations`): the supported, P1.S5-compatible way to translate our own strings.
- "Administration" is a literal in `nav-main.tsx` with no `Trans` wrapper, so a catalogue cannot reach it. Recorded in the handoff; not fixable without a core patch.
- `Language: English` is the user's `contentLanguage` setting, default `en` in `user-settings.tsx`, reset to the channel default only when not available on the channel. To be confirmed live against the seeded channel, then recorded.
