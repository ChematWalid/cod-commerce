## Method
A workflow ran each issue as implement (test first) → fresh reviewer → three adversarial verifiers (correctness, security, does-it-reproduce) → fix rounds. Round 0 closed 5 of 9; round 1 closed all 9 with every verdict present (an agent that returned nothing was re-run, and a missing verdict counted as not verified). Then a whole-branch review (correctness, security, §3a rules) with one should-fix finding, fixed, and a `security-review` pass.
