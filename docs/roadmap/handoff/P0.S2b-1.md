## Decisions
- ESLint 9.39.5 rather than 10, and TypeScript 5.9.3 rather than 7: the `typescript-eslint` and `eslint-plugin-boundaries` peer ranges, and Vendure's decorators, require them.
- Two independent layer checks, so a glob mistake in one can't silently disable enforcement:
  - ESLint `boundaries`, with element patterns `plugins/*/<layer>`; `plugin-root` is the folder element `plugins/*`;
  - dependency-cruiser, whose rules need `validate: true`, otherwise they are silently skipped.
- Workspace packages resolve to source through the custom export condition `@cod/source` in dev and test, and to `dist` in builds.
- Object storage is **Garage**, not MinIO (user decision; the MinIO image is no longer pullable).

## Gotchas
- **Command prelude.** Every command needs `export PATH="$HOME/.mise/installs/node/24.22.1/bin:$PATH"; export COREPACK_ENABLE_DOWNLOAD_PROMPT=0`: the host default is Node 26. Shell state does not persist between agent commands.
- **pnpm.** Use corepack: `corepack enable --install-directory "$HOME/.local/bin" pnpm`. Run it only from the repo root, after `packageManager` exists; otherwise it resolves to pnpm 12.
- **`pnpm ignored-builds`** prints "Cannot identify as no node_modules found" when nothing was ignored, so don't gate on that text; read `.modules.yaml`.
- **Garage.** The image has no shell: use exec-form healthchecks and run `/garage …` through `docker compose exec`.
- **Memory.** About 4.8 GB is free, so run builds one at a time with `NODE_OPTIONS=--max-old-space-size=2048`.
- **`docker compose down -v`** can take about 2 minutes locally.
- **zsh aliases** shadow `sed`, `grep`, `cat`, `cut`, `tr` and `ls`: use `command <tool>`. Never `pkill -f`.
