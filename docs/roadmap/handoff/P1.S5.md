## For the user to see
- **No `/en/…` or `/ar/…` URLs (D76).** Language is a per-user setting. The inventory row "Locale switch EN/AR with RTL layout" is ticked on that basis.
- **The stock store switcher and user menu are hidden by CSS** and replaced by ours (D79). A Vendure dashboard upgrade can break this; browser tests fail if it does.
- **Arabic copy needs a native review**, in particular: spam orders (الطلبات المشبوهة), customers (الزبائن or العملاء), credits (الرصيد), القوالب, البكسلات, دراسة المنتج, التقرير.
- **Local database:** an earlier task's live check tried four synthetic values from the project's own files against the local demo owner, and left four synthetic demo members in the local `cod` database (`limited@`, `orders@`, `noview@`, `perstore@demo.example.test`). Later tasks used disposable databases. You may want to delete those rows.

## Notes for later sessions
- **Fill a page:** `registerShellPage(leafId, Component)` from `@cod/plugin-merchant-shell/shell-api` (D83). The leaf ids, paths, permission keys and owning sessions are in `plugins/merchant-shell/dashboard/model/tree.ts`. A second registration for one leaf throws.
- **Store-scoped links:** build them with the shell-api path helpers; `/stores/active/…` follows the active store, a real store id is a deep link, and a foreign id shows not found.
- **New dashboard strings:** add them to the plugin's `ar.po` and `en.po`; ids built at runtime go in the plugin's `dashboard/i18n/dynamic-ids.ts`. `pnpm i18n:check` fails otherwise.
- **Styles:** logical properties only; the style gate fails on `ml-`, `left:`, colour literals and the like.
- **CI:** `browser.yml` now runs as four parts; it still runs only on pushes to main, nightly and on demand.
- **Create Store** polls for the new channel with backoff up to 10 s, because the session's channel list can lag the commit.
- **Platform staff** receive `PlatformStaff` through the superadmin role only; a real staff role is P10.S2.
