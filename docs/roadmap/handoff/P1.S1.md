# Handoff — P1.S1 (Business→Stores tenancy)

## Done
1. **`plugins/tenancy`.** Business, Store, CustomDomain and the per-business order sequence, with Channel-per-Store and Seller-per-Business provisioning in one transaction.
2. **Isolation by construction (ADR 0002 "As implemented").** `TenantEntity`, `TenantRepository`, `tenantQuery` with a locked builder, `TenantTransaction` (`set_config('app.business_id', …, true)`), `@TenantScoped`. Architecture gates: `gates/tenant-sql.ts`, the raw-access lint rule over `infrastructure/` and `api/`, and `plugin-core-no-tenancy-entry`.
3. **Host resolver.** LRU 60 s / 10k, then Valkey `host:{host}`, then DB, with pub/sub `host-invalidate` and a delayed re-delete. `GET /store/resolve` feeds the storefront proxy.
4. **Content language.** Store creation sets the channel default, so the owner's content language follows the store's.
5. **Shared and test code.** Snowflake ids as strings (`packages/shared/src/ids`), `createTwoBusinesses`, `asChannel`, `failureOf` in `packages/testing`; `plugins/_template` migrated; `seed:demo`.
6. **Evidence.** `docs/evidence/P1.S1/` from `scripts/evidence/P1.S1.sh`.

## Not fixed, and why
- **Store switcher shows the 32-character hex channel code, and archived stores stay in it.** Plan Task 4 mandates a random code, and the switcher is Vendure's stock one. **P1.S5 owns the switcher: it must show store names or subdomains and filter archived stores** (D18).
- **`[ioredis] Unhandled error event`.** Comes from clients inside `@vendure/job-queue-plugin` with no error listener (`bullmq-job-queue-strategy.js:125`, `redis-job-buffer-storage-strategy.js:23`), not our code.
- **`scripts/evidence/P0.S2b-6.sh` no longer runs.** The tenancy change broke it, and `template-screens.mjs` now signs in as an owner. Historical evidence stays valid.
- **Availability endpoint has no rate limit** yet: deferred to the launch edge rules; P1.S2 owns the wizard's limits.
- **Storefront store name is not revalidated on rename** until the publish flow, P3.S2 (D17).

## Decisions
D1–D18 in `docs/roadmap/P1-decisions.md`. D16 deviates from ADR 0006: host keys carry a 24 h backstop TTL.

## Deviations
- Compose defaults `PLATFORM_DOMAIN` to `platform.invalid`, because the portability gate forbids loopback there. Stacks needing `*.localhost` set it explicitly. It is validated at boot as a lowercase DNS name.
- `classifySubdomain` also rejects the `xn--` prefix (lookalike names), beyond the plan's format.
- The published evidence image is `4886c38`. The later fix wave changed boot validation, subdomain rules, lint and tests only, none of which appear in the evidence flows.
