## Gotchas
- The `@vendure/create --db postgres` CLI starts its own Postgres container on port 5432. The shared plan puts the compose Postgres on 5433 to avoid a clash.
- pnpm 10 blocks native build scripts. Add `pnpm.onlyBuiltDependencies` (bcrypt, better-sqlite3, esbuild, re2, sharp).
- Vendure has no `json` custom field type. Store JSON in a `text` field.
- A Vendure Promotion needs at least one condition. The spike used `has-quote-discounts`.
- Payment added outside the API's request handling needs a single transaction around the whole intake.
- Copying a scaffold with `node_modules` on Windows takes more than 5 minutes. Copy without `node_modules` and reinstall.
- The Playwright MCP writes a `.playwright-mcp/` folder into the cwd. Keep it out of the repo.
