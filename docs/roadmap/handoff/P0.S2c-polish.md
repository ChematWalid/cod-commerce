# Handoff — P0.S2c-polish (pre-P1 polish)

## Done
1. **Branding.** The login logo and welcome block are CodShop in Arabic and English, through the supported `login.logo` / `login.beforeForm` extension. `PRODUCT_NAME` is in `packages/shared/src/platform/brand.ts`. Browser test: `dashboard-branding.browser.test.ts`.
2. **Arabic strings.** "Merchant shell" and "Notes" are translated through plugin `.po` catalogues (en, ar: ADR 0005) with explicit ids and `i18n._()`, which stays compatible with P1.S5.
3. **RTL password field.** The placeholder was 4 CSS px off; fixed in `rtl.css`, asserted at 1280 and 390 px.
4. **Storefront stub.** Minimal styling, Arabic font, `lang`/`dir` per store locale, trilingual not-found page.
5. **Mobile evidence.** The open sidebar is captured in Arabic and English. Nothing broken was found.
6. **Several frontends.** `bearer-client.e2e.test.ts`, the live transcript `api/bearer-client.md`, and ADR 0017 (Proposed; merchants and shoppers).
7. **CLAUDE.md §3a.16-19**, confirmed by the user.

## Not fixed, and why
- **Login footer "Vendure v3.8.1" stays (user decision).** `@vendure/dashboard` forces it visible and calls it a licensing requirement; there is no supported override. Settle before production: ADR 0001 §8 counsel question. The same footer is on the forgot/reset-password pages and in the user menu.
- **"Administration" stays English.** It is a literal in `nav-main.tsx` with no translation wrapper, so a catalogue cannot reach it. Needs a core patch or an upstream fix.
- **Other visible Vendure surfaces, for P1.S5:** the user menu's "Plans" item links to vendure.io, and the favicon and the `description`/`author` meta tags are stock.

## Findings
- **"اللغة: الإنجليزية" is not a translation bug.** It is the user's content language: the client default is `en` (`user-settings.tsx`) and it changes only when the channel does not offer it. It should follow the store's language; P1.S1 store creation sets the channel default, and P1.S5 should default it for Arabic merchants.
- **ADR 0008's 30-day session is not in force:** `sessionDuration` is unset, so Vendure's default of 1 year applies. P1.S2 must set it (ADR 0017 §3).
- **Stock `logout` deletes all of a user's sessions** (ADR 0017 §3).

## Deviations
- **Not-found page shows all three languages at once** rather than the store's language. Next renders one not-found page with no store or params. Per-store root layouts failed `next build` under Cache Components ("Required root params", even with `generateStaticParams` on the layout and page), and a page calling `notFound()` is an error shell with no server markup (`internal-paths.ts`). P3.S2 owns per-locale root layouts.
- **`lang`/`dir` on store pages are set on the client** (`StoreDocumentLang`). The server HTML is `ar`/`rtl` until hydration, so a French store's raw HTML still says Arabic. P3.S2 replaces this.
- Brand constant path: `packages/shared/src/platform/brand.ts`, not ADR 0007's `packages/shared/brand.ts` (§3a.12).
- CLAUDE.md §3a.16-19 ship here rather than in a `docs/claude-md-*` PR (§3a.15), on the user's confirmation.
- The plan was committed before its fresh-agent review (§3a.13); the review ran right after and its findings are in the plan.
