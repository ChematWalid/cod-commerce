## Decisions
D3200–D3226 (full rows in `P3-decisions.md`):
- **D3200** one session, no a/b split, parallel waves.
- **D3201** tenancy owns the public tenant context (`StorefrontStoreGuard`); tenancy and rate-limit touched (deviation).
- **D3202** proxy rewrites to `/_t/{locale}/{storeId}/{binding}…`; HMAC binding of (store, host); mismatch is a soft 404.
- **D3203** `/store/resolve` and `/store/by-id` grow additively; `logo` kept as an alias for one release.
- **D3204** new outbox topic `store.changed` (settings, status, domain).

- **D3207** theme v0: `DEFAULT_THEME` and `COMPACT_THEME`, selected by `STOREFRONT_THEME`.
- **D3208** the spike E fixture is re-created in the repo and gates recall@5 ≥ 0.85.
- **D3209** images through a `next/image` loader mapped to Vendure asset presets.
- **D3210** CDN purge behind `CdnPurgePort`, logging no-op adapter, coalescer ≤ 1 per store per 30 s.
- **D3211** revalidate route at `/api/internal/revalidate`, signed `cod-internal-v1`.
- **D3212** JSON catalogues with an ICU-lite formatter, no `next-intl`.
- **D3213** public reads rate-limited per buyer, prefer the signed client ip; `STOREFRONT_TRUST_EDGE_IP`.
- **D3214** host LRU (10 000 entries, 60 s / 15 s negative), cache safeguards (512 KB cap, writes-off switch, 250 ms timeout).
- **D3215** storefront stays on port 3001.
- **D3216** tag revalidation deletes only the members it read; command timeout, lazy memory guard, `PLATFORM_DOMAIN` validated.
- **D3217** product image previews through `MediaStoragePort.previewsOf`.
- **D3218** `store.changed` written by `OutboxStoreChangedHook` inside the store transaction.
- **D3219** projection consumer and backfill read the catalog as the store; backfill is a 15-minute catch-up task; named indexes lead with `businessId`.
- **D3220** `cod_normalize_for_search` mirrors the TS normaliser; one trigram index; ranking without popularity boost.
- **D3221** single root layout with `<div lang dir>` (deviation, Next 16.4.5 bug); binding gate in the `[binding]` layout.
- **D3222** revalidate consumer queues a coalesced `storefront-revalidate` job; worker calls the storefront.

## Deviations from the plan/brief
- **D3201:** tenancy and rate-limit touched, though the brief lists only storefront files as owned. Reviewed exports only (`StorefrontStoreGuard`, `@StorefrontCtx()`, `StorefrontStoreContexts.forStore`).
- **D3202:** the rewrite is locale first with the binding after the store id; a mismatch renders a **soft 404 with HTTP status 200** (Cache Components cannot set a status from a tenant render), `noindex`. D3223 amends D3221 b: a valid binding whose path names the store's previous language renders in the current language instead of a soft 404.
- **D3221:** one root layout (`app/layout.tsx`); `app/%5Ft/[locale]/layout.tsx` renders `<div lang dir>` and a client component sets `<html lang dir>` after hydration. A server-rendered `<html lang dir>` per store language fails `next build` on Next 16.4.5 (encoded-folder root-layout bug). Follow-up #286.
- **D3219:** the projection backfill is a catch-up task, not a bootstrap hook; a rebuild also walks catalog pages.
- **D3220:** SQL normaliser mirrors the TS one with built-ins and does not wrap `unaccent`; one combined trigram index; no `to_tsvector` index.
- **D3224:** the id gate is a local ESLint rule, not `no-restricted-syntax` entries (a later block would replace them).
- **D3216:** tag revalidation does not `DEL` the whole index; the memory guard polls lazily, not on a timer.
- **Brief's `demo.localhost:3000` is `demo.localhost:3001`** (D3215): 3000 is the api port.

## For the user to see
- **ADR 0006 addendum to accept** (appended to `docs/adr/0006-*`, recorded as accepted under the standing P3 authorization): the `/_t/{locale}/{storeId}/{binding}` rewrite and its binding (D3202), Vendure presets instead of WebP derivatives for now (D3209), `/api/internal/revalidate` (D3211). Also a `store.changed` row in the shared-contracts table of `docs/roadmap/README.md`.
- **Soft-404 behaviour:** a page whose host binding does not match answers a "not found" page with status 200 and `noindex`, not a real 404 (D3202). Real 404 stays for unknown hosts, unknown slugs and refused `/_t` paths. Decide if that is acceptable for search engines; the window after a host or language change is #287.
- **`STOREFRONT_TRUST_EDGE_IP` must be `true` when deployed, and the origin must be locked to Cloudflare** (D3226 d). Otherwise every buyer shares one rate-limit key, or the header can be forged. The firewall rule is on the P3.S5 checklist.
- **The CDN purge is a no-op** until a Cloudflare token exists (D3210). P3.S5 checklist: the adapter, the edge rules for `/api/internal/*`, a rate-limit rule on `/search` and `/api/store/*`, and a cache rule that never stores 5xx or 429.
- **Store theme switch is an env var** (`STOREFRONT_THEME=default|compact`, D3207) until per-store theme storage in P8.S1.

## Gotchas
- **Build `packages/shared` first** (`pnpm --filter @cod/shared build`): the storefront imports its `dist`.
- **Next encoded-folder root-layout bug** (D3221): do not move `<html lang dir>` into `app/%5Ft/[locale]/layout.tsx`; re-test when Next is upgraded (#286).
- **`PLATFORM_DOMAIN` is required** in staging and production for api and storefront; `localhost` elsewhere (D3216 d). Hosts outside `<label>.<PLATFORM_DOMAIN>` get 404 with no api call.
- **Seeds run as the business owner** so the media library resolves the store (`146512e8`); a seed with no user creates products without images.
- **Evidence build can exceed the command timeout on a loaded host:** prebuild the image, then run with `EV_SKIP_BUILD=1`.
- The signed internal calls need the HMAC keys in `.env`; never print them. Slugs may hold letters of any language and arrive percent-encoded (decoded once, `408555d8`).
