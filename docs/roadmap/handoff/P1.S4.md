## Gotchas
- **`pnpm test:arch` fails 16–18 `boundaries/no-unknown-files` tests on `__lint_fixture__` paths** only when the repository sits under `.claude/` (agent worktrees). Judge it from a clone outside `.claude/`; there it passes.
- **Team test servers** must create the partitioned tables (`activity_log`, `outbox_event`, through `withPartitionedSchemas`) and send a fresh `x-test-client-ip` on each sign-in, or the shared login-ip budget refuses later logins.
- **Heavy-lock rule:** a server started in the background under `$HEAVY` must close the inherited lock fds (`3>&- 4>&- 5>&- 6>&- 7>&- 8>&- 9>&-`) and be stopped by an `EXIT` trap of the same locked command. An orphaned server holds the shared lock and blocks every lane.
- Integration runs need `DATABASE_URL_DIRECT`; a fresh worktree has no `apps/server/.env`, so use the `.env.example` values for the local compose stack.
