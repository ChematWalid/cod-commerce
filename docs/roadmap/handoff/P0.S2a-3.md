## Gotchas
- **Vendure search indexing fails silently** if the default channel has no tax zone (`error.no-active-tax-zone` on every `update-search-index` job). Seed the default channel's zones before importing products.
- In Next 16 App Router, folders starting with `_` are private: name the internal route folder `%5Ft` to serve `/_t/…`, and make `proxy.ts` 404 public `/_t` and `/%5Ft` paths.
- `next start` evaluates `next.config.ts` again, so env-driven `deploymentId`/handler settings must be identical at build and start.
- `revalidateTag(tag, profile)` needs two arguments in Next 16 and does not work inside `proxy.ts`.
- Postgres `unaccent` is not IMMUTABLE; wrap it with an explicit dictionary in an IMMUTABLE function before indexing.
- Meilisearch: set `localizedAttributes` ara on the index; typo tolerance skips Arabic words under 5 letters.
- Cloudflare Free: purges are limited to 5 requests per minute per account, so coalesce and batch them.
- Machine gotchas (shell aliases, `pgrep -f` self-kill, HDD vs SSD) are in the P0.S2a-2 handoff.
